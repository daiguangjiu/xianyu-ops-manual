🔑 第二章 账号注册与基础搭建

2.1 注册流程（标准操作）

  1. 下载闲鱼APP：通过官方应用商店下载，勿用第三方修改版。
  2. 注册/登录：使用手机号注册淘宝账号 → 自动关联支付宝。已有淘宝/支付宝账号可直接登录。
  3. 绑定支付宝：进入「我的」→「设置」→「支付设置」→ 绑定已实名认证的支付宝账号。
  4. 设置头像和昵称：头像用真实/半真实照片（增加信任感），昵称简洁易记，建议与经营类目相关。
  5. 完善个人资料：填写个人简介、所在城市、性别等基础信息。简介中可自然嵌入经营方向。 一个身份证可实名认证 3个支付宝账号，对应可开 3个闲鱼账号。但需配合3个不同手机号，且遵守"一机一卡一号"原则。

2.2 实名认证

认证类型 要求 路径
基础实名 身份证 + 人脸识别 我的 → 设置 → 账号与安全 → 实名认证
支付宝实名 需与闲鱼账号绑定的支付宝已完成实名 支付宝APP → 我的 → 设置 → 账号与安全
企业蓝V认证 营业执照 + 法人身份信息 需通过官方渠道提交

建议优先完成支付宝高级实名认证（绑定银行卡），可提升账号权重和交易额度。

2.3 芝麻信用分与闲气值

指标 满分 合格线 影响
芝麻信用分 950 ≥ 650（优秀≥700） 影响商品排名权重、买家信任度、超级擦亮投放资格
闲气值 100 ≥ 80（鱼小铺门槛） 低于80无法开通鱼小铺；低于60限制发布商品

提升芝麻信用分：完善学历/职业信息、按时还花呗/借呗、多使用支付宝线下支付、保持稳定收货地址。

2.4 认证招商与经营资质上传

「认证招商」是闲鱼为经营性卖家提供的资质认证入口。完成经营资质上传后，账号将获得企业/个体工商户标识，解锁更多经营工具和流量权益。对于月流水超5万或经营品牌商品的卖家，建议尽早完成认证。

2.4.1 认证招商入口位置

进入路径：闲鱼APP → 我的 → 认证招商（或 设置 → 认证招商）

在「认证招商」页面中，可以看到以下模块：

  • 经营资质 — 上传营业执照，完成企业/个体户认证
  • 品牌资质 — 品牌授权书上传（经营品牌商品时需要）
  • 行业资质 — 特定行业许可（如食品经营许可证等）

2.4.2 经营资质类型与所需材料

资质类型 适用对象 需上传材料
个人认证 个人卖家（默认） 身份证 + 支付宝实名即可，无需额外操作
个体工商户 有个体营业执照的卖家 营业执照原件照片/彩色扫描件 + 法人身份证正反面
企业认证 有公司营业执照的商家 营业执照 + 法人身份证 + 对公银行账户（可选）+ 企业支付宝

2.4.3 经营资质上传操作步骤（6步）

  1. 进入认证招商：打开闲鱼APP → 点击右下角「我的」→ 找到「认证招商」入口（或在「设置」中查找）。
  2. 选择经营资质：进入「认证招商」页面后，点击「经营资质」选项。
  3. 点击立即开通：在经营资质页面，点击「立即去开通」按钮。
  4. 选择资质类型：根据实际情况选择「个体工商户」或「企业」，然后点击「下一步」。
  5. 阅读并确认承诺函：仔细阅读《确认函》内容，确认无误后点击「下一步」。
  6. 填写信息并提交：在「新增认证」页面，逐项填写对应信息（企业名称、统一社会信用代码、法人信息等），上传营业执照照片和身份证照片，点击「提交」等待审核。

2.4.4 审核要点与避坑指南

审核要点 具体要求 常见被拒原因
执照有效期 剩余有效期最好大于6个月 执照已过期或临近过期
照片质量 清晰完整、无反光、无水印、四角完整 照片模糊、反光严重、边缘裁剪不完整
信息一致性 执照法人 = 闲鱼实名认证人 = 支付宝实名认证人 法人信息与账号实名不一致
经营范围 执照经营范围需包含销售相关类目 经营范围与在售商品不符
填写准确性 填写信息必须与执照完全一致（包括标点符号） 公司名漏字、信用代码错位

⚠️ 审核注意事项：

• 审核周期：通常 3-5个工作日，高峰期可能延长至7天

• 审核通过后，建议第二天再上架商品，更稳妥

• 审核失败可重新提交，注意查看拒绝原因中的具体说明

• 认证免费，无需支付任何费用（警惕"代认证"收费骗局）

7.2 超级擦亮投放指南（大鱼动力）

闲鱼官方的付费推广产品正式名称为「超级擦亮」（不少资料写作「超强擦亮」，指的是同一产品），通过闲鱼官方商业化投放平台「大鱼动力」投放，计费支持按曝光（CPM）与按点击（CPC），可选推广目标为：曝光量、浏览量、关注收藏量、咨询量。2026 年升级后它不再是简单的"花钱擦一下"，而是精准流量匹配系统——系统根据商品标题、属性、历史成交数据，主动把商品推送给近期浏览/搜索/收藏过类似商品的高意向买家。本质是用预算撬动数据资产，投放沉淀的点击、咨询、收藏数据会反向抬升账号整体流量表现。

7.4 闲鱼圈子（社区）规则与玩法全攻略（2026版）

闲鱼圈子（含「会玩」圈子、神奇鱼塘、广场）是闲鱼内基于兴趣与需求的垂直社交场景。它的流量逻辑独立于商品搜索列表：靠内容种草把人吸进来，靠兴趣标签把流量导向商品，最后靠真实互动完成信任转化。一句话总结核心玩法——内容种草 + 精准引流 + 信任转化；规则核心——严禁站外引流 + 内容真实合规 + 互动提升权重。

7.4.1 圈子基础规则（2026年最新）

① 准入与权限

  • 加入圈子后需先完成新手任务（如签到、评论）才能发帖；部分高活跃度圈子设有等级门槛，等级不够只能看不能发。
  • 发布商品同步到圈子时，必须选择与商品强相关的圈子（如「数码玩家」「考研自习室」「宠物交流圈」），或选择人气值 > 5000 的鱼塘。人气值过低的鱼塘没有分发能力，同步过去等于白发。

② 内容发布规范

  • 禁止发布广告、外链、二维码、联系方式（含微信、QQ、手机号及其谐音变体）。例外：2026 年起平台开放了官方留联系方式通道，合规做法见 7.4.3 ②，勿用谐音 / 图片藏号等土办法。
  • 二手商品分享需关联真实宝贝链接，不得发布虚假商品或误导性描述。
  • 禁止政治宣传、封建迷信、淫秽色情、赌博暴力、欺诈虚假、侵犯知识产权、侮辱诽谤等内容。
  • 文案禁用极限词（「最好」「第一」「全网最低」）、高仿词（「精仿」「原单」）、敏感词及站外引流词。
  • 同一商品每周最多在 2 个不同鱼塘同步发布，避免重复内容被判定后降权。

③ 违规处置

  • 轻则下架 / 删除 / 屏蔽 / 降权；重则限制发布、互动、交易、加入鱼塘，甚至封号。圈子场景最高频的违规（站外引流、禁售品类、色情低俗与擦边）具体处罚口径见 7.4.3 ① ③ ⑤。
  • 情节严重者会被建立违规公示名单并公开披露，涉嫌违法的移送国家机关。

  • 操作：发布商品时勾选「同步到圈子」，或在「会玩」板块的圈子内直接发布动态 / 笔记，正文末尾插入商品链接。
  • 技巧：
    • 同一商品制作 2–3 条不同话术的动态，分别发布至不同鱼塘，每条间隔 ≥ 15 分钟。
    • 圈子动态配图用商品实拍图，正文通常不写售价，只描述成色或征询意见（如「刚淘到一台 XX，成色惊喜，想听听老哥们怎么看」）。
    • 发布后 2 小时内回复至少 3 条圈子内其他用户的评论，连续 3 天保持互动可提升账号权重。

玩法2：创意内容霸屏法

  • 操作：在「会玩」板块（圈子 + 广场）发布原创创意帖，争取首页推荐，获取百万级曝光。
  • 技巧：
    • 内容方向：使用教程、经验分享、开箱测评、避坑指南等有价值的内容，而非硬广。
    • 标题前 15 字权重最高，需包含品牌词、属性词、场景词、长尾词及城市标签。
    • 上传 9–12 秒功能演示短视频，系统识别为高价值内容并给予额外推荐权重。
    • 带上平台热门话题标签（如 #二手好物），蹭话题流量池——这是成本最低的固定蹭曝光动作。

玩法3：垂直圈层深耕法

  • 操作：选择一个垂直领域（如宠物用品、数码配件、汉服洛丽塔等），持续在对应圈子内输出内容，建立专业人设。
  • 技巧：
    • 账号标签要纯——系统基于兴趣标签而非关键词匹配推荐，标签越纯，精准流量转化率越高。
    • 在圈子内对同类优质笔记做真实评论和点赞，提升账号在该圈层的权重。
    • 粉丝沉淀：设置「粉丝专享价」引导关注，定期发布粉丝专属内容，提升复购率并享受评价分加成。

玩法4：同城流量截流法

  • 操作：关闭定位，手动选择一二线城市发布，利用本地流量权重获取精准买家。
  • 技巧：
    • 适合同城配送 / 自提的商品（如室内绿植、二手品牌家具、宠物用品等）效果最佳。
    • 结合时间节点（毕业季 4–6 月、年底离城潮、购物节后）蹲点高校或大城市低价扫货。

玩法5：AI 工具辅助法

  • 操作：使用闲鱼 AI 相机拍照自动识别物品、估价并生成文案；使用 AI 智能定价，基于近 3 个月成交数据给出建议价。
  • 技巧：
    • 「AI 帮聊」可自动回复常见问题及智能议价，提升回复率与权重。
    • 「闲鱼空间」可拍摄全景照批量识别物品并估价发布，大幅提升上架效率。

证据层 留痕备查 发货视频、聊天记录、物流单号保存至少3个月

第一步：确认风险类型

  1. 检查近7天操作记录：是否批量注册、多账号共用网络、同一设备切换账号、异常IP登录。
  2. 检查交易行为：是否高频买卖给同一对象、是否有买家投诉、是否有虚假发货。
  3. 检查商品内容：是否误触禁售品类、是否使用违禁词、是否引导站外。
  4. 检查矩阵关联：同一身份证/手机号/设备/网络下其他账号是否同时异常。
  5. 检查登录环境：是否使用了VPN/代理IP、是否异地登录频繁。

  • 标记高风险设备和网络，后续不再使用

  • 调整养号节奏，降低操作频率

官方计分逻辑（重要，勿按「累计扣分」理解）：闲鱼的信用分叫闲气值，满分 100 分，当前闲气值 = 100 − 近 90 天内因违规被扣分数的总和；扣到 0 分后分值不再变化。也就是说——违规记录会在 90 天内滚动生效、90 天后自动恢复，不存在「攒够 20 分降权」这类累计阈值。

⚠️ 典型扣分示例（官方规范）：引导站外交易一般扣 1 分、严重扣 20 分、特别严重扣 100 分；刷单/虚假交易属扰乱平台秩序，严重 40 分、特别严重 100 分；售假被权利人投诉同一自然年累计 3 次 → 扣 100 分且分值不再恢复、永久限制。

15.1 卖方软件服务费收费规则

这是所有闲鱼卖家必须了解的核心规则，直接影响利润核算。

费用类型 收费门槛 费率 计算基数
基础软件服务费 所有成交订单（无门槛） 0.6%（普通卖家单笔封顶 60 元；鱼小铺卖家不封顶） 每笔订单成交额
软件服务费-基础门槛 当月累计成交＞10单 且 累计金额＞10,000元 1%（超出门槛部分） 超出门槛的每笔订单成交额
软件服务费-品类门槛（手机） 当年手机品类累计成交＞6笔 1%（超出门槛部分） 超出门槛的手机品类每笔订单成交额
软件服务费-鱼小铺 开通鱼小铺工具服务的卖方 1%（所有订单） 每笔订单成交额

关键要点：

  • 费率上限：普通卖家同一笔订单最多收取 0.6%（基础）+ 1%（软件服务费）= 1.6%，且基础服务费单笔封顶 60 元；鱼小铺卖家不享受封顶、费率不设金额上限（鱼小铺销售手机品类综合费率最高约 2.6%）
  • 计费基数（2026年4月18日起）：按确认收货时的订单成交额计算，含运费、平台红包与平台补贴——此前按「实际成交额」计，新口径会让服务费明显高于以往，定价时必须计入
  • 基础门槛 vs 品类门槛：同一订单同时满足时，仅按品类门槛收取（不重复收）
  • 鱼小铺卖家：不再享受"基础门槛"和"品类门槛"的优惠政策，每笔订单都收取1%+0.6%
  • 退款不退费：成交后发生退款，已划扣的软件服务费不做退还
  • 扣款方式：由支付服务商从买家支付的订单款项中实时划扣
  • 手机品类统计：从每年1月1日起统计交易成功订单，超出6笔后开始收费
  • 规则生效：2024年9月1日起实施基础软件服务费；2026年4月18日最新修订 运营启示：对于月销超1万或手机品类活跃卖家，需将1.6%的服务费纳入定价成本核算。鱼小铺卖家需特别注意——一旦开通，每单都收费，小额多单模式成本更高。

核心原则：走真实，不吃电商风

闲鱼是真实用户社区，不是纯电商平台。所有增长策略必须建立在真实交易、真实互动、真实内容的基础上。禁止刷单、互赞、虚假发货、批量铺货等电商化操作。

D.6 每日数据复盘流程（10分钟）

  1. 录入数据（2分钟）：在决策系统中录入当日花费、曝光、点击、咨询、成交、退货数据。
  2. 检查预警（2分钟）：对照D.3监控指标，标红异常项（ROAS不达标/退货率超标/CTR过低等）。
  3. 决策动作（3分钟）：关停不达标计划 → 递增优质计划预算 → 替换低CTR素材 → 调整出价。
  4. 记录笔记（2分钟）：简要记录当日关键决策和原因（为什么关/为什么加/为什么换）。
  5. 每周校准（1分钟）：积累7天真实数据后，更新决策系统中的漏斗系数（CPC/CTR/咨询率/成交率），让模型越来越准。 关键原则：测款期重在「快」——多条计划快速试错淘汰；放量期重在「稳」——聚焦Top计划，严控ROAS和退货率；维稳期重在「收」——降出价、精选时段、集中预算清仓。每个阶段关键指标达标后再进下一阶段，不要跳步。

E. 固定提醒

  1. 资料归档运营资料库：所有投放数据、复盘笔记、素材素材迭代记录，统一归档到团队共享文档/网盘，便于后续复盘和新人培训。
